How to restore

  1. Stop the website and the timer runner.
  2. On the server, in the Find-IT folder with the virtual environment active, check the file: python manage.py restore_db FILE_NAME --check-only
  3. Restore it: python manage.py restore_db FILE_NAME and type RESTORE when asked. The current database is backed up first as a pre-restore file.
  4. Run python manage.py migrate, then start the site again.
