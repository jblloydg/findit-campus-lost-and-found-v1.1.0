How to restore

  1. Stop the website and the timer runner.
  2. List backups: python manage.py backup_now --list
  3. Restore: python manage.py restore_backup NAME and type RESTORE. A safety backup of the current state is made first.
  4. Start the site again.

Full procedure: docs/OPERATIONS.md.
