{% comment %}CHG-015: how a post's status changes. Nobody types a status: Find-IT sets it from what people do, and "At Guard House" can only be set by a staff member (guard) who has the item in hand.{% endcomment %}
How does the status change?
  • Open for Claim — every new post starts here.
  • Claim in Progress — set by Find-IT when someone claims a found item or a finder starts verifying the owner of a lost item.
  • At Guard House — only a guard (staff) can set this, by scanning the finder's turn-in QR or code, or by recording a walk-in. Students can't set it.
  • Returned — the finder marks it returned to an approved owner; Claimed — the owner confirms they received it (or a guard confirms the pickup).
  • Closed — the author or staff closed the post.
